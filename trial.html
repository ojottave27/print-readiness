Every figure is checked by recomputing each label's region from the finished SVG, not by trusting the code that placed it. Determinism is checked by rendering twice and comparing sha256 - the same bytes, every run.

2. Label clearance: the algorithm

Each primitive exposes a signed distance: a circle returns |dist(centre) - r|, a segment the point-to-segment distance, a polygon the minimum over its edges.

For every label I generate candidate positions and score each one against every stroke and every other label. Clearance is measured on the real glyph outlines (fontTools path bounds), never estimated text boxes - that is the mistake that lets a test pass while the figure still looks crowded.

If no candidate fits, the label moves outside with a short leader line. The line's path is tested too: if it would cross another label, it is not drawn.

Why I trust the tests. An earlier version passed its own clearance test while placing a label inside the wrong shape, and another passed with a label 135 px from what it named. Both were caught by measuring, not by looking. The clearance test now includes a counter-test: move a label one pixel toward a line and it must fail. A test that cannot fail is not a test.

3. Devanagari, end to end

क्षेत्र   क्रम   पहाड़   मीटर   सेमी

uharfbuzz shapes the text using the font's GSUB/GPOS tables; fontTools converts each glyph to outlines. The SVG carries paths, never <text>, so the output does not depend on the reader having the font installed. PNG uses skia-python with the glyphs already shaped.

Evidence: क्षेत्र (7 characters) produces 3 glyphs, including uni0915094D0937 and uni0924094D0930. The 094D is the virama - the signature of a real ligature. क्रम produces 2 glyphs. पहाड़ produces uni095C.

4. Libraries and byte-identical output

uharfbuzz, fontTools, shapely, skia-python, pydantic, fastapi, pytest. All MIT/BSD/Apache - no GPL or AGPL. PyMuPDF was discarded specifically because it is AGPL.

Byte-identical because: floats formatted at fixed precision; stable write order (no unsorted dict/set iteration); no timestamps or random IDs inside the file; fonts pinned in the repository and used by path, not by system lookup. Verified by rendering twice and comparing sha256.
